# Market Mood 3

미국 · 한국 · 크립토 시장의 **투자심리 · 주요 가격 · 경제지표**를 10초 안에 파악하는 모바일 우선 금융 대시보드입니다.
한국어 기본, 반응형 웹, 설치 가능한 PWA.

> **본 서비스는 정보 제공 목적이며 투자 조언이 아닙니다.**
> 화면에 표시되는 Fear & Greed 점수는 공개·라이선스 데이터로 직접 계산한 **자체 산출 지수**이며, 외부 기관의 공식 지수가 아닙니다.

## 1. 실행 방법

### 사전 요구사항

- Node.js **20.9 이상** (개발은 22.x 기준)
- npm 10 이상

### 설치 · 실행

```bash
npm install

# 개발 서버 (http://localhost:3000)
npm run dev

# 프로덕션 빌드 & 실행
npm run build
npm start
```

API 키가 하나도 없어도 **DEMO 모드로 바로 실행**됩니다. 별도 설정 없이 모든 화면과 상태를 확인할 수 있습니다.

## 3. 실제 데이터 API 연결 위치

모든 실데이터 연결은 **한 파일**에 모여 있습니다.

### 📍 `src/server/adapters/live/index.ts`

`MarketAdapter` 인터페이스를 구현한 `LiveAdapter` 클래스입니다. 각 메서드에 `TODO(연결지점 N)` 주석과 함께 구현 위치가 표시되어 있습니다.

| # | 메서드 | 붙일 데이터 |
| --- | --- | --- |
| 1 | `getQuotes(market)` | 시장별 시세 목록 |
| 2 | `getFngInput(market)` | Fear & Greed 원시 지표 시계열 |
| 3 | `getBenchmark(market)` | 점수와 겹쳐 볼 대표 지수 (미국 S&P 500 / 한국 KOSPI / 크립토 BTC) |
| 4 | `getFlows()` | 한국 투자자별 순매수 (외국인·기관·개인) |
| 5 | `getMacro()` | 거시·위험 지표 |
| 5-2 | `getBasics()` | 생활 속 경제 이야기 (1인당 GDP·지니계수·빅맥지수·PPP 환율·엥겔계수·PIR·경기선행지수·소비자심리지수) |
| 5-3 | `getPrediction()` | 예측시장에서 화제인 질문 (폴리마켓) — **유일하게 실제 구현이 들어있는 연결지점** |
| 6 | `getCalendar()` | 경제 캘린더 (KST `+09:00` 로 정규화) |
| 7 | `getNews()` | 뉴스 (헤드라인·매체·발행시각·원문 링크) |
| 8 | `getAssetSeries(id, range)` | 종목 상세 차트 (1D 분봉 / 나머지 일봉) |
| 9 | `getUsdKrw()` | 통화 전환용 환율 |

구현 시 반드시 지킬 것:

- 외부 호출은 **반드시 `fetchJson()`** (`src/server/http.ts`)을 통해 — 타임아웃·제한적 재시도·호스트별 요청 제한이 적용됩니다.
- 값이 유한한 숫자가 아니면 **0 이 아니라 `null`** 로 두고 `unavailableReason` 을 채웁니다.
- `meta.asOf` 는 제공사가 준 기준 시각을 그대로 사용하고, `meta.sources[].delayMinutes` 에 계약상 지연 시간을 정확히 기입합니다.
- 제공사 약관상 실시간 재배포가 금지된 경우 지연 데이터를 사용하고 지연 시간을 표기합니다.
- 뉴스 본문 재배포가 금지된 경우 헤드라인·링크만 저장하고, 한국어 요약은 `summaryOrigin: 'derived'` 로 표시합니다.

## 4. Fear & Greed 자체 산출 방식

외부 서비스의 지수를 복제하지 않고 직접 계산합니다.

1. 구성요소별 원시 지표를 수집합니다.
2. 각 지표를 **최근 252거래일**(크립토는 365일) 분포와 비교해 0~100 백분위로 변환합니다.
3. 상·하위 **2.5% winsorization** 후 백분위를 계산해 극단치 영향을 줄입니다.
4. 값이 클수록 공포인 지표(VIX, 풋/콜, 신용스프레드 등)는 방향을 반전해 **높은 점수 = 탐욕**으로 통일합니다.
5. 하위 지표 → 구성요소 → 최종 점수 순으로 가중평균합니다.
6. **결측을 0점으로 처리하지 않습니다.** 사용 가능한 구성요소 가중치 합이 **70% 이상**일 때만 그 안에서 가중치를 재조정해 계산하고, 미만이면 점수를 숨기고 **"산출 불가"** 로 표시합니다.
7. 데이터 충족률과 신선도를 조합해 신뢰도를 **높음/보통/낮음** 으로 표시하고, 산식 버전(`v2.1.0`)을 함께 기록합니다.

### 구성요소 가중치 (각 합계 100%)

**미국** — CNN Fear & Greed Index 가 공개한 7가지 축과 **같은 항목**을 쓰고, CNN 과 마찬가지로 **동일 가중**입니다
(정수 가중치 합을 100 으로 맞추려 두 항목만 15%).

| 축 | 무엇을 보는가 | 가중치 |
| --- | --- | --- |
| 시장 모멘텀 | S&P 500 vs 125일 이동평균 | 15% |
| 주가 강도 | 52주 신고가 vs 신저가 종목 수 | 15% |
| 주가 폭 | 오른 종목·내린 종목의 거래량 차이 누적 | 14% |
| 풋/콜 옵션 | 주식 옵션 풋/콜 비율 5일 평균 | 14% |
| 시장 변동성 | VIX vs 자기 50일 이동평균 | 14% |
| 안전자산 선호 | 주식 20일 수익률 − 국채 20일 수익률 | 14% |
| 정크본드 수요 | 하이일드 스프레드 | 14% |

> **항목은 같지만 숫자는 다릅니다.** CNN 의 값을 가져오는 게 아니라, 같은 성격의 데이터를 받아 이 앱의 산식
> (역사적 분포 백분위 → 가중평균)으로 직접 계산합니다. 그래서 같은 날 두 숫자가 다를 수 있고 그게 정상입니다.
> 화면에도 이 문장을 그대로 노출합니다. 공식 지수가 아닙니다.

**한국·크립토** — 대응되는 공개 지수가 없어 시장 특성에 맞게 직접 구성했습니다.

| 한국 | | 크립토 | |
| --- | --- | --- | --- |
| KOSPI 모멘텀·이동평균 이격도 | 20% | BTC·ETH 및 전체 시장 모멘텀 | 20% |
| VKOSPI 수준과 변화 | 20% | 변동성·고점 대비 낙폭 | 18% |
| 상승/하락 종목 및 시장 폭 | 15% | 주요 코인 이동평균 상회 비율 | 12% |
| 외국인·기관 순매수 흐름 | 15% | 현물 거래량·거래 강도 | 10% |
| 선물·옵션 풋/콜 및 파생 심리 | 10% | 펀딩비·미결제약정·청산 | 15% |
| USD/KRW 급등·환율 변동성 | 10% | 스테이블코인·온체인 자금 흐름 | 8% |
| 신용잔고·투자자예탁금·KOSDAQ 상대강도 | 10% | BTC 도미넌스·알트 시장 폭 | 10% |
| | | 검색 관심도와 뉴스 심리 | 7% |

**축의 개수는 미국 7 · 한국 7 · 크립토 8 입니다.** 미국은 CNN 이 공개한 7축을 그대로 쓰고, 한국은 그에 맞춰
7축으로 짰습니다. 크립토만 여덟인 이유는 **검색 관심도와 뉴스 심리(7%)** 를 더했기 때문입니다 — 공개된 다른
크립토 공포·탐욕 지수들이 공통으로 쓰는 축인데 빠져 있었습니다. 개수는 `scripts/verify.mjs` 가 못 박아 두어,
말없이 늘거나 줄면 검증이 실패합니다.

### 다른 공포·탐욕 지수를 참고해 정한 것

공개된 다른 지수들의 방법론을 훑어보고 넣고 뺀 결과를 `COMPOSITION_NOTES` 에 적어 두고, 각 시장의
`/fng/[market]` 화면 상단에 그대로 노출합니다. **어느 지수의 값도 가져오지 않습니다.** 참고한 것은 "무엇을 보는가"뿐입니다.

| 시장 | 넣은 것 | 넣지 않은 것과 이유 |
| --- | --- | --- |
| 미국 | 공개된 7축 그대로 | 개인투자자 설문(AAII)·운용사 노출도(NAAIM) — 재배포 조건이 명확하지 않음 |
| 한국 | **투자자예탁금 20일 증감률** (국내에서 오래 쓰인 대기 매수 자금 지표) | — |
| 크립토 | **검색 관심도** (다른 코인 지수들이 공통으로 쓰는 축인데 빠져 있었음), 변동성 비중 15% → 18% | SNS 게시물 수 — 봇 계정을 걸러낼 방법이 없음 |

점수 단계: `0~19 극단적 공포` / `20~39 공포` / `40~59 중립` / `60~79 탐욕` / `80~100 극단적 탐욕`

> 세 시장 모두 0~100 척도를 쓰지만 **구성 지표와 가중치가 다르므로 직접 비교 대상이 아닙니다.** 이 경고는 홈 화면과 상세 화면에 항상 노출됩니다.

가중치·구성요소를 바꾸려면 `src/server/fng/definitions.ts` 만 수정하면 됩니다. 산식이 바뀌면 `FORMULA_VERSION` 을 올려 과거 점수와 구분하세요.

### 심리 사이클

점수 하나만으로는 부족합니다. 같은 45점이라도 80점에서 내려온 45점과 20점에서 올라온 45점은 다릅니다.
그래서 모든 시장 점수에 **사이클**을 함께 산출합니다.

- **기간별 심리 위치** — 단기(20일) · 중기(60일) · 장기(250일) 각 구간에서 현재 점수가 놓인 백분위, 평균, 범위, 기간 시작 대비 변화
- **현재 국면** — `현재 수준(공포/중립/탐욕) × 최근 10일 방향(상승/횡보/하락)` 조합
  - 공포+상승 = **회복 시도** / 공포+하락 = **공포 심화**
  - 중립+상승 = **개선** / 중립+하락 = **약화**
  - 탐욕+상승 = **과열 진행** / 탐욕+하락 = **탐욕 후퇴**
- 20일 이동평균과 10일 기울기(점/일)를 함께 표시

국면은 **서술이지 예측이 아닙니다.** 지금의 수준과 방향에 이름을 붙인 것일 뿐, 다음 방향을 말하지 않습니다.
홈의 각 심리 카드에 국면 배지가 붙고, `/fng/[market]` 상세에서 기간별 위치를 모두 볼 수 있습니다.

구현: `src/server/fng/cycle.ts` 의 `buildCycle`

### 구간별 과거 통계

"이 점수 구간이던 날들 이후 대표 지수가 어떻게 움직였는가"를 집계해 보여줍니다.
각 단계별 표본 일수, 이후 20거래일 수익률의 평균·중앙값·플러스 비율·최저·최고.

**매매 신호가 아닙니다.** 과거 표본의 분포일 뿐이고, 표본이 겹치는(overlapping) 구조라 통계적 독립성도 없습니다.
그 한계를 화면에 그대로 적어 둡니다. DEMO 모드에서는 합성 데이터로 계산되므로 실제 시장 통계가 아니라는 경고가 함께 표시됩니다.

구현: `src/server/fng/cycle.ts` 의 `buildBandStats`

### 10년 히스토리와 과거 위기 표식

상세 화면(`/fng/[market]`)의 기간 선택에 **10년**이 있습니다. 과거 위기 시점에는 세로 점선과 번호 배지를 찍고,
바로 아래 목록에 같은 번호로 사건 이름·날짜·그때의 점수·단계를 붙여 둡니다. 목록 항목을 누르면 해당 시점을
차트에서 강조하고, 보고 있는 기간 밖이면 자동으로 10년으로 넓힙니다.

사건 목록은 `src/server/fng/events.ts` 의 `MARKET_EVENTS` 한 곳에 있습니다. 항목을 더하거나 빼려면 여기만
고치면 되고, 각 항목은 `markets` 로 어느 시장에 표시할지 지정합니다. 기준일은 "공포가 가장 심했던 날"로
잡습니다 — 예를 들어 2025년 관세 급락은 발표일(4/2)이 아니라 반등 직전 저점인 4/8 을 씁니다.

**무엇이 사실이고 무엇이 산출값인지 구분합니다.**

| 항목 | 성격 |
| --- | --- |
| 사건의 날짜·이름·설명 | 실제로 있었던 일 (앱이 만들지 않음) |
| 표식에 붙은 점수 | **이 앱의 자체 산식**이 그 시점 데이터로 계산한 값 — 외부 기관 공식 지수가 아님 |
| DEMO 모드의 점수 | 원본이 합성 데이터이므로 점수도 합성 — 그날의 실제 수치가 아님 |

마커마다 `synthetic` 플래그를 두고, 화면에도 위 구분을 그대로 적습니다. 히스토리 범위를 벗어난 사건은
억지로 끌어오지 않고 개수만 알리며(`outOfRange`), 점수가 결측인 날에 걸리면 값을 지어내지 않고 사유를 남깁니다.

읽히게 만들기 위해 둔 장치:

- 몇 년에 걸친 구간에서는 축·표·툴팁 라벨에 **연도**를 넣습니다. 월·일만 쓰면 10년이 며칠짜리 구간처럼 읽힙니다.
- 3년·10년 구간의 선은 **20일 평균**입니다. 하루치 점수는 진폭이 커서 몇 년을 한 화면에 그리면 형태가 보이지
  않습니다. 이 사실과 "목록의 숫자는 평균이 아니라 그날의 실제 점수"라는 점을 캡션에 적습니다.
- 점 추출은 `decimateMinMax` 로 구간별 **실제 최저·최고**를 남깁니다. n개마다 하나 고르는 방식은 고른 날에
  따라 위기 저점이 통째로 빠질 수 있습니다. 없는 값을 지어내지 않습니다.

구현: `src/server/fng/events.ts`, `src/components/market/CrisisMarkers.tsx`,
`src/components/charts/InteractiveChart.tsx` 의 `ChartMarker`

> DEMO 세계(`src/server/adapters/demo/world.ts`)는 실제 위기 날짜에 충격을 재현해 넣습니다. 그러지 않으면
> "코로나19 팬데믹" 표식이 합성 세계의 평온한 구간에 찍혀 극단적 탐욕으로 표시되어, 기능 확인용 데이터로
> 쓸모가 없습니다. DEMO 는 화면 어디에나 배지가 붙는 합성 데이터이므로 이 재현이 실데이터와 섞일 여지는 없습니다.

## 5. 시장 위험 신호등

> **시장은 항상 하나만 고릅니다 — "전체"는 없습니다.** 미국 VIX 와 크립토 펀딩비를 한 줄에 섞어
> "빨간불 1개"라고 세면 그 1개가 어느 시장 이야기인지 알 수 없습니다. 열리는 시간도 움직이는 이유도
> 다른 시장이라 하나로 합친 목록 자체가 의미가 없습니다.
>
> 같은 규칙을 `/risk` · `/indicators` · `/calendar` 세 화면에 모두 적용했습니다. 기본값은 미국이고,
> 어느 한 시장에 묶이지 않는 **글로벌 항목**(미국 10년물·달러지수·금·유가, 글로벌 일정)은
> 어느 시장을 골라도 함께 보여줍니다 — 미국 탭에서 사라지면 놓치는 항목이 생기기 때문입니다.
>
> 요약(한 줄·신호등 집계·단계 분포·표)도 전부 고른 시장만 셉니다. 아래 카드는 크립토인데 위 숫자가
> 전체이면 읽을 수가 없습니다. 문장 규칙은 서버와 화면이 갈라지지 않도록 `src/lib/riskHeadline.ts`
> 한 곳에서 공유합니다.
>
> 중요도·분류 필터의 "전체"는 그대로입니다. 그건 서로 다른 시장이 아니라 같은 목록을 좁히는 조건입니다.

> **투자심리 점수의 구성요소와는 다른 것입니다.** 헷갈리기 쉬운 지점이라 화면에도 적어 둡니다.
>
> | | 시장 위험 신호등 (`/risk`) | 투자심리 구성요소 (`/fng/[market]`) |
> | --- | --- | --- |
> | 무엇인가 | 미국·한국·크립토 위험을 한 판에 모은 대시보드 | 심리 점수를 만드는 재료 |
> | 왜 VKOSPI·원/달러·펀딩비가 있나 | 세 시장을 모두 다루기 때문 | 미국 점수에는 들어가지 않음 |
> | 점수를 만드나 | 아니오 (구간 판정만) | 예 (가중평균해서 0~100) |


시장 위험을 읽는 핵심 게이지 7개만 추려 별도 화면(`/risk`)과 홈 요약으로 제공합니다.

| # | 지표 | 시장 | 무엇을 보는가 |
| --- | --- | --- | --- |
| 1 | 미국 공포지수 VIX | 미국 | S&P 500 옵션이 반영한 향후 30일 예상 변동성 |
| 2 | 한국 공포지수 VKOSPI | 한국 | KOSPI200 옵션 기반 국내 변동성 |
| 3 | 하이일드 신용스프레드 (정크본드) | 미국 | 저신용 기업이 국채 대비 더 무는 금리 — 기업 자금 사정 |
| 4 | 미국 장단기 금리차 (10년-2년) | 미국 | 역전 여부 — 과거 경기침체에 앞서 나타난 신호 |
| 5 | 미국 국채 10년물 금리 | 글로벌 | 전 세계 자산 가격의 기준 금리 |
| 6 | USD/KRW 환율 | 한국 | 원화 약세 → 외국인 자금 이탈·수입물가 압력 |
| 7 | 크립토 선물 펀딩비 | 크립토 | 레버리지 쏠림 — 연쇄 청산 위험 |

각 지표는 **안정 / 보통 / 관찰 / 주의** 4단계로 표시합니다.

- 구간 경계는 `src/server/risk.ts` 의 `RISK_SEVEN` 에 명시되어 있고, **화면에도 그대로 노출**합니다. 숨은 기준을 두지 않습니다.
- 구간 막대 위에 현재 값의 위치를 찍어, 숫자만으로는 알 수 없는 "지금 어디쯤인가"를 보여줍니다.
- 단계는 색상뿐 아니라 기호(○ ● △ ▲)와 라벨로도 표시합니다.
- 지표마다 **무슨 지표인가**(고정 설명), **지금 읽는 법**(현재 구간에 해당하는 해석), 그리고
  **값이 오르면 / 내리면 무슨 일이 벌어지는가**를 함께 제공합니다. 지표 이름과 숫자만으로는 처음 보는 사람이
  방향의 의미를 알 수 없기 때문입니다.
- 값이 없으면 0 이 아니라 "값 없음 + 사유"로 표시하고 종합 집계에서 제외합니다.
- 새 데이터 소스를 쓰지 않고 이미 수집한 시세·거시 지표에서 파생하므로, LIVE 어댑터를 붙이면 자동으로 함께 동작합니다.

#### 눈금 끝은 위험의 끝이 아닙니다

막대의 `scaleMax` 는 **그리는 범위일 뿐 상한이 아닙니다.** 과거 극단값까지 눈금에 담으면 평상시 움직임이
한 점으로 뭉개져서, 눈금은 평소 범위에 맞추고 벗어난 값은 따로 표시합니다.

일곱 지표를 확인해 보니 **전부 과거 극단값이 눈금 밖**이었습니다. 예를 들어 VIX 막대는 40까지만 그리는데
2020년 3월에는 82.69(종가)까지 갔습니다. 그래서 지표마다 `scaleNote` 에 눈금이 어디까지인지와 과거엔 얼마나
더 갔는지를 적어 막대 아래에 그대로 노출합니다.

값이 눈금을 벗어나면 조용히 가장자리에 붙이지 않습니다. `offScale` 로 내려보내 **"눈금 밖"** 이라고 적고
막대 밖으로 화살표를 내밉니다. 구간 판정(예: `28 이상`)은 원래부터 열려 있으므로, 잘리는 것은 그림이지
판정이 아닙니다.

> 구간 기준은 이 앱이 정한 값이며 공식 기준이 아닙니다. 단계 표시는 위험의 방향을 읽는 참고이며 매매 신호가 아닙니다.

### 지표 해설 (초보자용)

`/indicators` 의 지표 23개마다 접이식 해설을 답니다.

| 줄 | 내용 |
| --- | --- |
| 이게 뭔가 | 한두 문장으로 푼 정의 |
| 기준 | 언제를 100으로 놓았는가 (기준점이 있는 지수만) |
| ▲ 오르면 | 값이 오를 때 시장에서 실제로 벌어지는 일 |
| ▼ 내리면 | 값이 내릴 때 벌어지는 일 |

원칙:

- 오르내림을 **좋다·나쁘다로 쓰지 않습니다.** "무슨 일이 벌어지고 있다"로만 씁니다.
- 한 방향이 늘 같은 뜻은 아닌 지표(유가·10년물 금리·배당수익률 등)는 **그 사실을 문장에 적습니다.**
  예: "경기 침체 걱정으로 돈이 국채로 몰려서 내려가는 경우도 있어, 왜 내렸는지를 같이 봐야 합니다."
- 화살표는 값의 방향일 뿐이므로 **등락 색(빨강·파랑)을 쓰지 않습니다.**
- 목록 스캔을 방해하지 않도록 기본은 접혀 있고, 누른 항목만 펼칩니다.
- **기준점이 있는 지수는 그것부터 알려 줍니다.** "3,714" 나 "104" 같은 숫자는 언제를 100으로 놓았는지
  모르면 읽을 방법이 없습니다. DXY 1973년 3월 = 100, KOSPI 1980-01-04 = 100, KOSDAQ 1996-07-01 = 1,000,
  KOSPI 200 1990-01-03 = 100 은 종목 상세에도 적습니다.

해설은 값이 아니라 **지표의 정체**에 붙는 고정 문구라 `src/lib/indicatorGuide.ts` 한 곳에 둡니다.
어댑터와 무관하므로 실데이터를 붙여도 그대로 쓰입니다.

### 생활 속 경제 이야기 (`/basics`)

시세가 아니라 **살림살이의 크기**를 재는 숫자를 따로 모은 화면입니다. 뉴스에 나오는 용어를 알아듣기 위한
배경 지식이고, 투자심리 점수의 구성요소가 아닙니다. 대부분 1년에 한두 번 바뀌므로 그날의 시장을 설명하지 않습니다.

아홉 개가 있어 **무엇을 재는 숫자인지로 묶어** 보여줍니다 (`BASIC_GROUPS`). 묶음마다 어떻게 읽어야 하는지를
한 줄 달고, 마지막 묶음은 근거가 약한 것들이라는 사실을 묶음 차원에서 먼저 알립니다.

지표마다 **한국·중국·일본·미국** 네 나라를 늘 같은 자리·같은 순서로 놓습니다. 카드마다 순서가 달라지면
여러 카드를 훑을 때 눈이 자리를 다시 찾아야 하기 때문입니다. 한국이 항상 맨 앞이고 강조 표시가 붙습니다.

**나라 살림과 소득** — 모두 공식 통계

| 지표 | 재는 것 | 발표 |
| --- | --- | --- |
| 1인당 GDP | 나라가 1년에 만든 부가가치 ÷ 인구 | 연 1회 (World Bank / IMF) |
| 지니계수 | 소득이 얼마나 고르게 나뉘었나 (0~1) | 연 1회 (통계청 / OECD) |
| 미저리 지수 | 물가상승률 + 실업률 = 체감 고통 | 매월 (두 지표를 더해 계산) |

**물가로 견주는 지수** — 품목 하나로 재는 것일수록 오차가 큼

| 지표 | 재는 것 | 발표 |
| --- | --- | --- |
| 빅맥지수 | 같은 햄버거 값으로 견준 통화 저·고평가 | 연 2회 (The Economist) |
| 구매력평가(PPP) 환율 괴리 | 물가 바구니로 계산한 적정 환율과 시장 환율의 차이 | 연 1회 (OECD / IMF) |
| 엥겔계수 | 가계 소비지출 중 식료품 비중 | 연 1회 (통계청) |
| 소득 대비 주택가격 (PIR) | 집값이 연 소득의 몇 배인가 | 분기 (KB / 국토부 등) |

**경기를 앞서 읽는 지수** — 방향을 보는 것이지 시점을 맞히는 도구가 아님

| 지표 | 재는 것 | 발표 |
| --- | --- | --- |
| OECD 경기선행지수 (CLI) | 경기 방향을 6~9개월 앞서 — 100이 장기 평균 | 매월 (OECD) |
| 소비자심리지수 (CCSI) | 가계가 느끼는 살림살이 — 100이 기준선 | 매월 (한국은행) |

> **전부 통계기관이 발표하는 공식 지표입니다.** 발표 기관이 없는 개념(라떼지수·버핏지수·립스틱지수·
> 펜타곤 피자지수 같은 것)은 담지 않습니다. 근거의 무게가 섞이면 목록 전체의 신뢰가 그 최저치로 떨어지기
> 때문입니다. 검증 스크립트가 `official === true` 를 전 항목에 대해 확인합니다.

지표 해설과 같은 원칙 위에 두 줄을 더 답니다.

- **조심할 점** — 이 숫자로 하면 안 되는 해석을 적습니다. (평균이라 분배를 못 보여준다, 재미로 만든 지수다 등)
- **시장 이야기와의 연결** — 어떤 맥락에서 인용되는지만 적고, 매매 판단으로 잇지 않습니다.
- 카드마다 **"공식 통계 / 비공식 개념"** 배지 자리를 그대로 둡니다(`official`). 지금은 전부 공식이지만,
  나중에 비공식 개념을 다시 넣더라도 그 사실이 화면에 저절로 드러나게 하기 위해서입니다.
  지금 목록은 모두 발표 기관이 있어 LIVE 어댑터에서 그대로 받아올 수 있습니다.
- 비교 막대는 **단위가 같고, 부호가 한쪽으로 몰려 있고, 값 차이가 뚜렷할 때만** 그립니다.
  원·달러·%를 한 축에 올리면 길이가 아무 뜻도 갖지 못하고, 부호가 섞이면 길이가 무엇을 뜻하는지 알 수 없습니다.
  전부 음수인 값(통화 저평가율 등)은 **크기**로 길이를 재 "얼마나 벗어났나"를 보여줍니다.
- **같은 잣대가 아닌 값에는 막대를 아예 그리지 않습니다** (`sameScale: false`). 소비자심리지수는 한국·중국이 100,
  일본이 50, 미국이 1985년=100 기준이라 애초에 견줄 수 없습니다. 글로 "견주지 말라"고 적어 둬도 길이를 그려 주면
  눈이 먼저 비교해 버리기 때문에, 경고문이 아니라 그림을 뺍니다.
- 그대로 견주면 안 되는 지표에는 비교표 **바로 아래**에 `※` 로 이유를 답니다(`comparisonNote`).
  숫자를 나란히 놓는 순간 사람은 비교부터 하므로, 경고가 표 위가 아니라 아래에 있어야 눈에 들어옵니다.
- 나라 비교가 성립하지 않는 지표가 들어오면 **네 나라 숫자를 지어내지 않고** 왜 없는지를 적습니다(`comparisonNote`).

서로 맞물린 숫자는 **한 곳에서만 정의합니다.** 미저리 지수는 지표 화면에 나오는 CPI·실업률을 그대로 더한 값이라,
DEMO 어댑터가 두 곳에 따로 적지 않고 `FIXED_MACRO` 한 곳을 봅니다 (검증 스크립트가 두 화면의 일치를 확인합니다).

**오늘의 경제 이야기** — 홈에 하루 한 가지씩 띄웁니다. 열세 개를 한 번에 읽으라고 하면 아무도 읽지 않기 때문입니다.
`dailyBasicId(kstDateKey)` 가 KST 날짜로 항목을 정하므로 무작위가 아닙니다. 같은 날 몇 번을 열어도 같은 항목이고,
하루가 지나면 다음으로 넘어가 **9일이면 전부 한 번씩** 돕니다 (검증 스크립트가 확인합니다).
스냅샷이 실제로 내려준 항목 중에서만 고르므로 목록이 바뀌어도 빈 카드가 나오지 않습니다.

값은 어댑터(`getBasics()`)에서 오고 개념 해설·묶음만 `src/lib/economyBasics.ts` 에 둡니다. DEMO 값은 DEMO 월드의
USD/KRW 에서 계산해 화면 안에서 앞뒤가 맞도록 했고, 출처에 합성 데이터임이 그대로 표시됩니다.

### 예측시장에서 화제인 질문 (홈의 별도 칸)

폴리마켓 같은 예측시장에서 거래가 활발한 질문 2개를 홈의 별도 칸에 보여줍니다.
시세와 성격이 달라 가격 카드에 섞지 않고 따로 뒀고, 계속 바뀌므로 갱신 주기가 가장 짧습니다(TTL 60초).

**여기 숫자는 확률이 아니라 가격입니다.** 68¢ 는 "그 일이 일어난다"에 사람들이 1달러 중 68센트를 내고 있다는
뜻일 뿐, 실제로 그렇게 될 확률이 68%라는 보장이 아닙니다. 이 문장을 카드 아래에 항상 노출합니다.
예측시장은 투자상품이 아니고 이 앱은 거래를 중개하지 않는다는 안내, 국내에서는 이용이 제한될 수 있다는 안내도
함께 답니다.

- 값이 가장 높은 선택지를 크게 보여주고, **24시간 변화폭도 같은 선택지 기준**으로 맞춥니다
  (선택지가 셋 이상이면 어디에 붙는 값인지 알 수 없어 변화폭을 버립니다).
- 막대에는 등락색도 신호등색도 쓰지 않습니다. 어느 쪽이 비싼지를 보여줄 뿐 유불리를 뜻하지 않기 때문입니다.
- 질문 원문은 대개 영어입니다. 서버에서 번역하지 않고 **원문 그대로** 내려보내고 화면에 그 사실을 적습니다.
  DEMO 는 한국어 샘플 질문을 쓰고 `questionOrigin: 'derived'` 로 표시합니다.
- DEMO 는 **실제 폴리마켓 질문을 베끼지 않습니다.** 뉴스와 같은 규칙으로 존재하지 않는 샘플 질문을 쓰고
  원문 링크를 비워 둡니다. 가격만 DEMO 월드(단기금리·BTC)에서 끌어와 화면 안에서 앞뒤가 맞게 했습니다.

**LIVE 연결 상태.** `getPrediction()` 은 다른 연결지점과 달리 API 키가 필요 없어 **실제 구현이 들어 있습니다**
(`gamma-api.polymarket.com`, `POLYMARKET_API_BASE` 로 교체 가능). 다만 이 저장소를 만든 환경에서는
polymarket.com 으로 나가는 통신이 막혀 있어 **응답 필드 이름을 실제 호출로 확인하지 못했습니다.**
문서에 적힌 모양(`question` / `outcomes` / `outcomePrices` / `volume24hr` / `endDate` / `oneDayPriceChange`)을
기준으로 썼고, 값이 예상과 다르면 추측해 채우지 않고 그 시장만 결측 처리합니다.
처음 붙일 때 응답 한 건을 찍어 필드명을 확인하세요.

> 모드는 여전히 스냅샷 단위로 하나입니다. DEMO 모드에서 이 칸만 실시간 값을 가져오는 일은 없습니다.

## 7. 검증

서버를 띄운 상태에서:

```bash
npm run build && npm start &
npm run verify
```

`scripts/verify.mjs` 가 요구사항의 검증 기준을 자동 확인합니다 (총 152건).

- 미국·한국·크립토 카드 정상 표시
- 모든 점수가 0~100 범위 (구성요소·하위 지표·전체 히스토리 포함)
- 구성요소 가중치 합계 각각 100%, 하위 지표 내부 가중치 합계 100%
- 미국 구성요소가 7축(모멘텀·강도·폭·풋콜·변동성·안전자산·정크본드) 그대로이고 사실상 동일 가중
- 결측을 0으로 처리하지 않음 / 70% 미만이면 산출 불가 + 사유 제공
- 재조정된 적용 가중치 합계 100%
- 점수 상세에서 산식·기여도·출처 확인 가능
- 모든 가격에 기준 시각과 지연 여부 표시
- 6가지 DEMO 상태 재현
- 시장 위험 신호등: 구간이 빈틈·중복 없이 이어지고, 표시 단계가 실제 값의 구간과 일치
- 심리 사이클: 기간 3개, 백분위 0~100, 국면이 실제 점수 수준과 일치
- 구간별 과거 통계: 5개 구간 집계, 표본 부족 구간은 null, 한계 경고 문구 존재
- 10년 히스토리: 점수·비교 가격 모두 9년 이상, 시간 오름차순
- 과거 위기 표식: 히스토리 범위 안, 사건일에서 7일 이내, 점수 0~100, 결측이면 사유 제공,
  DEMO 에서는 `synthetic` 플래그가 반드시 켜짐, 표식 점수 중앙값이 전체 중앙값보다 낮음
- 시장별 분리 화면(`/market/us` · `/market/kr` · `/market/crypto`)과 `/indices` · `/risk` 렌더링
- `/api/health` 에 키 값 미노출

### 반응형 · 접근성

- 375px / 태블릿 / 데스크톱에서 **가로 스크롤 없음** (홈의 심리 카드 가로 스와이프는 컨테이너 내부 스크롤)

### 홈에서 덜어낸 것

"정보가 너무 많아 읽기 불편하다" 는 지적을 받고 홈의 글자를 세어 가며 덜어냈습니다 —
**2,938자 → 2,259자 (−23%), 3,736px → 3,237px (−13%)**. 기능은 그대로고, 다른 데서 이미 말한 것과
"문제가 없다" 는 말을 지웠습니다.

| 덜어낸 것 | 왜 |
|---|---|
| 상태바의 통화 · 색상 전환 | **더보기 → 표시 통화 / 등락 색상에 이미 있습니다.** 한 번 정하면 며칠씩 그대로 두는 설정이라 모든 화면 맨 위에 늘 띄울 것이 아니었습니다 (4줄 → 2줄) |
| `수신 방금` | `마지막 전체 업데이트` 와 거의 늘 같은 값이라, 나란히 두면 무엇이 다른지 알 수 없었습니다 |
| 심리 카드의 `신뢰도 높음` | 늘 붙어 있으면 배지가 아니라 장식입니다. 낮을 때만 뜨게 하면 그때 눈에 걸립니다 |
| 심리 카드의 `1주` `1개월` | 심리 상세의 **기간별 심리 위치**가 훨씬 잘 보여줍니다. 홈에는 `어제보다` 하나만 |
| `하락 요인 판단할 데이터가 부족합니다` | 없다는 말을 읽게 할 이유가 없습니다. 카드 셋이 서면 그 줄만 세 번 보였습니다 |
| `산출 14:46 · 충족률 100%` | 100%라고 매번 적어 두면 정작 90%로 떨어진 날을 놓칩니다. 온전하지 않을 때만 |
| 신호등 집계 칸의 지표 이름 | 바로 아래 게이지 일곱 장이 이름을 댑니다. 한 화면에서 일곱 이름을 세 번 읽고 있었습니다 |
| 가격 카드 여덟 장의 `출처 …` 줄 | 카드마다 구분선 + 한 줄이 여덟 번. 기준 시각은 기호 옆으로 옮기고, 출처는 종목 상세가 말합니다 |
| 세 줄짜리 척도 경고 | 한 문장으로. 카드 셋을 지나자마자 회색 덩어리를 만나면 그 아래가 읽히지 않습니다 |

미리보기도 같이 줄였습니다. 통화 · 색상 전환은 앱 화면에서 뺀 대신 **미리보기 자신의 조작 줄**로 옮겨,
전환 동작은 그대로 눌러 볼 수 있습니다.

**시장은 탭이 아닙니다.** 홈의 심리 카드마다 `○○ 시장 →` 버튼이 있어 거기서 바로 들어갑니다.
시장을 고르기만 하던 허브 화면(`/market`)은 홈과 내용이 겹쳐 없앴고, 바깥 링크가 깨지지 않도록
지수 화면으로 넘깁니다.

**대신 지수가 탭입니다.** 지수는 종목과 성격이 다릅니다 — 살 수 있는 물건이 아니라 시장의 온도계라서,
홈의 `관심 가격과 주요 지수` 안에서 삼성전자 옆에 KOSPI 가 붙어 있으면 무엇을 보고 있는지 흐려집니다.
`/indices` 에 세 시장의 지수를 모아 두고, 홈에는 그리로 가는 길만 남겼습니다.

**그 탭은 두 보기를 갖습니다.**

| 보기 | 주소 | 무엇을 재나 |
|---|---|---|
| 시장 지수 | `/indices` | KOSPI · S&P 500 · VIX … **시장**을 재는 눈금 |
| 생활 경제 지수 | `/basics` | 빅맥지수 · 1인당 GDP · 엥겔계수 … **살림살이**를 재는 눈금 |

둘 다 지수지만 재는 대상이 다릅니다. 예전에는 생활 경제 지수(`/basics`)가 홈의 `경제 이야기` 칸과
사이드바에서만 들어갈 수 있어 찾기 어려웠습니다. 칸을 하나 더 늘리지 않은 것은 **320px 에서 일곱 칸이면
글자가 뭉개지기** 때문이고, 지표 화면에서 이미 쓰는 방식(`[위험 신호등 | 전체 지표]`)과도 같아서입니다.

두 주소가 각각의 보기로 열립니다. 바깥에서 들어온 링크(`/basics`)는 제 보기로 열리고, 하단 탭의 `지수` 는
두 주소 모두에서 활성으로 표시됩니다.

**버튼을 누를 때는 주소를 건드리지 않습니다.** 보기를 바꾸는 일은 화면을 옮기는 일이 아니기 때문입니다.
처음에는 `router.push` 로, 다음에는 `history.replaceState` 로 주소를 갈아 끼워 봤는데 둘 다 같은 문제를 냈습니다 —
Next 가 주소 변경을 화면 이동으로 받아 맨 위로 스크롤합니다. 누를 때마다 보던 자리를 잃고 뒤로가기가 탭을
벗어나지 않아, 다른 화면으로 넘어간 것처럼 읽혔습니다.

| | 고치기 전 (`router.push`) | 지금 (그 자리에서) |
|---|---|---|
| 내용이 바뀌는 데 | 42~74ms | **8~9ms** |
| 스크롤 | 150 → **0 으로 튐** | **150 그대로** |
| 뒤로가기 | 반대쪽 보기로 (히스토리 +1) | 탭을 벗어남 (히스토리 그대로) |

잃는 것은 "지금 보기를 주소로 건네주기" 하나뿐이고, 두 주소가 그대로 살아 있어 링크로 특정 보기를 여는 일은
여전히 됩니다.

`지수` 와 `지표` 는 한 글자 차이라 10px 로 나란히 놓으면 구분되지 않습니다. 지표 쪽 탭 이름을
**`경제지표`** 로 늘렸습니다. 320px 에서도 여섯 칸이 줄바꿈 없이 들어갑니다 (가장 긴 글자 40px / 칸 53.3px).

**위험 신호등도 별도 화면이 아닙니다.** 예전 `/risk` 는 `/indicators` 와 시장 필터도 같고 지표도 겹쳐서,
같은 VIX 를 두 화면에서 보게 되고 어느 쪽이 최신인지 헷갈렸습니다. 지표 화면 하나에
`[위험 신호등 | 전체 지표]` 보기를 두고 합쳤습니다. `/risk` 는 그쪽으로 넘깁니다.

- `/market/us` · `/market/kr` · `/market/crypto` — 시장 전용 화면.
  해당 시장의 심리 카드, 관련 위험 지표, 시장 고유 지표(미국: 금리·달러·원자재 / 한국: 지수·국고채·투자자 수급 / 크립토: 시총·도미넌스·파생),
  시세 목록, 그 시장 관련 일정과 뉴스만 들어갑니다.

**홈 화면 순서**

요약까지가 "10초 안에 파악"이고, **그 아래는 탭으로 나눠 한 번에 하나만 봅니다.**

1. 시장 상태와 업데이트 시각 (상단 상태바 — KST 시각, 미국·한국 세션, 크립토 24시간, LIVE/지연/오래됨/DEMO 배지, 통화·색상 전환)
2. Fear & Greed 카드 3개 (모바일 가로 스와이프 / 데스크톱 3열, 카드마다 `○○ 시장 →` · `심리 상세 →`)
3. 시장 위험 신호등 요약 (종합 한 줄 + 7개 타일)
4. 관심 가격과 주요 지수 (관심목록 · 홈 표시 항목 순 최대 8개 + `지수 전체 →` 링크)
5. 오늘의 시장 요약 (사실/해석 구분). **위 카드들이 이미 보여준 것은 다시 적지 않습니다** — 세 점수와 대표 시세를 늘어놓던 두 줄을 빼고, "오늘 가장 크게 움직인 것" 과 그 원인만 남겼습니다
6. `[일정 | 자금·뉴스 | 예측시장 | 경제 이야기]` 탭

예전에는 6~9번이 전부 세로로 이어져 모바일에서 **5,688px**, 데스크톱에서는 2열로 갈라 놨는데 두 열의 길이가
달라 왼쪽 아래에 **270px 짜리 빈 자리**가 생겼습니다. 탭으로 나눈 뒤 모바일 3,877px / 데스크톱 2,535px 이 되고
빈 자리도 사라졌습니다.

고르지 않은 탭은 **그리지 않습니다.** 감춰 두기만 하면 화면에는 안 보여도 스크린리더와 탭 이동에는 그대로
남아 길이가 줄지 않기 때문입니다. 어느 탭에 있었는지는 기억하지 않습니다 — 홈은 열자마자 오늘 일정이 보이는
편이 낫고, 마지막에 본 탭이 무엇이었는지는 대체로 기억나지 않습니다.

**상세 화면**

- `/fng/[market]` — 1M/3M/1Y/3Y/10Y 점수 차트, 과거 위기 시점 표식, 대표 지수 겹쳐보기, 구성요소 전체 점수·가중치·하위 지표, 기여도, 산출 방법, 출처, 결측·신뢰도 설명

- `/indices` — **지수 → 시장 지수.** 미국 · 한국 · 크립토를 한 화면에 나란히. 지수마다 기준점을 그 줄에서 밝히고, 각 묶음에서 그 시장 화면으로 들어갑니다
- `/basics` — **지수 → 생활 경제 지수.** 빅맥지수 · 1인당 GDP 등 아홉 가지를 세 묶음으로. 지표마다 한국·중국·일본·미국 비교 (개념 · 읽는 법 · 조심할 점 · 시장 이야기와의 연결)
- `/indicators` — 경제·위험 지표. **미국·한국·크립토** 중 하나 + `[위험 신호등 | 전체 지표]` 보기 (지표마다 "이게 뭔가 / 기준은 무엇인가 / 오르면·내리면 무슨 일이 생기나" 접이식 해설)
- `/calendar` — **전체 / 미국·한국·크립토** + `[달력 | 목록]` 보기 + 중요도·카테고리 필터. 달력에서 날짜를 누르면 그날 일정만 아래에 펼침
- `/alerts` — 알림 규칙 관리

### 차트 조작 (점수 추이 · 자산 상세)

시계열 라인 차트는 끌어서 다룹니다. **지금 전체가 보이는지 아닌지에 따라 끌기의 뜻이 달라집니다.**

| 상태 | 끌기 | 휠 · 두 손가락 | 두 번 누르기 |
|---|---|---|---|
| 전체가 보임 | **구간 고르기** — 끄는 동안 띠가 그려지고, 손을 떼면 그 구간만 확대 | 확대 (축소 방향 휠은 페이지 스크롤로 넘김) | — |
| 확대한 상태 | **좌우로 이동** | 커서 위치 기준 확대·축소 | 전체로 되돌림 |

전체가 보이는 상태에서는 좌우로 밀어 봐야 갈 데가 없어 끌기가 아무 일도 하지 않았습니다. 그 자리를
구간 고르기에 씁니다. 고른 폭이 전체의 2% 도 안 되면 손이 미끄러진 것으로 보고 확대하지 않습니다.

띠는 고르는 동안 SVG 안의 전용 `<g class="sel">` 노드만 다시 그립니다. 차트 전체를 다시 그리면 끌고 있는
동안 노드가 갈아치워져 포인터 캡처가 끊깁니다.

키보드로도 같은 일을 합니다 — `Shift`+`←`/`→` 이동, `+`/`−` 확대·축소, `0` 전체. 확대·축소·전체 버튼도
차트 옆에 그대로 있습니다. 세로 터치 스크롤은 `touch-action: pan-y` 로 브라우저에 넘겨,
차트 위에서 위아래로 쓸면 페이지가 스크롤됩니다.

스파크라인·게이지·구간 막대는 시간축이 없거나 손톱만 한 그림이라 조작 대상이 아닙니다.

### 지수 화면 (`/indices`)

**무엇을 세우는가.** 개별 종목이 아니라 시장 전체를 한 숫자로 재는 값만 모읍니다 (`INDEX_IDS`, `src/lib/catalog.ts`).

| 시장 | 지수 |
|---|---|
| 미국 | S&P 500 · Nasdaq Composite · Dow Jones · Russell 2000 · VIX · 달러지수 DXY |
| 한국 | KOSPI · KOSDAQ · KOSPI 200 · VKOSPI |
| 크립토 | 전체 시가총액 · 24시간 거래량 · BTC 도미넌스 · 스테이블코인 시총 |

**크립토에는 공식 지수가 없습니다.** KOSPI 나 S&P 500 에 해당하는 것이 존재하지 않아, 시장 전체 크기를
재는 값들을 대신 놓고 화면에서 그렇다고 밝힙니다. 없는 것을 있는 척 만들어 붙이지 않습니다.

**기준점을 그 줄에서 밝힙니다.** `3,714` 라는 숫자 자체는 아무 뜻이 없습니다 — 언제를 100(또는 10, 135,
1,000)으로 놓았는지를 알아야 읽힙니다.

| 지수 | 기준 |
|---|---|
| S&P 500 | 1941~1943년 평균 = 10 |
| Nasdaq Composite | 1971년 2월 5일 = 100 |
| Dow Jones | 기준값 없음 — 30개 종목 주가를 더해 제수로 나눈 값. 1896년 5월 26일 40.94 로 시작 |
| Russell 2000 | 1986년 12월 31일 = 135 |
| KOSPI | 1980년 1월 4일 = 100 |
| KOSDAQ | 1996년 7월 1일 = 1,000 (처음에는 100 이었고 2004년에 고쳐 매김) |
| KOSPI 200 | 1990년 1월 3일 = 100 |
| 달러지수 DXY | 1973년 3월 = 100 |
| VIX · VKOSPI | 기준 시점 없음 — 예상 변동폭을 연율 % 로 나타낸 값 |

기준이 **없는** 경우에도 "없다"고 적습니다. 빈칸으로 두면 아직 안 넣은 것인지 원래 없는 것인지 알 수 없습니다.

**고르게 하지 않습니다.** 세 시장을 한 화면에 나란히 쌓습니다. 다 합쳐도 열네 개라 한 번에 훑는 편이 빠르고,
미국이 빠졌는지 한국이 빠졌는지도 바로 보입니다. 데스크톱에서는 3열, 모바일에서는 세로로 이어집니다.

**목록은 카탈로그가, 값은 API 가 정합니다.** 어떤 지수가 있는지는 정적으로 알고 있으므로 이름·기호·기준점은
값이 오기 전에도 그대로 서 있고, 숫자 자리에만 빈 칸이 뜹니다. 화면이 통째로 회색 덩어리였다가 갑자기
바뀌면 무엇을 기다리는지 알 수 없습니다. 값을 못 받은 줄은 지우지도 0 으로 채우지도 않고 그 줄에서 사유를 적습니다.

미리보기 HTML 도 같은 목록과 기준점을 씁니다 — `tools/preview/build.mjs` 가 `src/lib/catalog.ts` 에서
직접 읽어 담습니다. 손으로 베끼면 어긋나고, **기준점이 어긋난 지수는 숫자 자체가 거짓말이 됩니다.**
카탈로그 모양이 달라져 읽지 못하면 조용히 비우지 않고 빌드를 세웁니다.

### 눌리면 안 되는 것 (글자 겹침)

가로 배치(`display:flex`) 안에서 배지나 글리프는 기본값이 `flex-shrink: 1` 입니다. 옆에 긴 문단이 오면
**배지 상자가 제 글자보다 작게 눌리고, 글자는 상자를 넘어 문단 위로 올라탑니다.** 요약 카드의 `사실` · `해석`
배지가 문장과 겹쳐 보이던 것이 이것이었습니다 — 배지 상자는 26px 인데 글자는 37px 이 필요했습니다.

| 자리 | 증상 | 고침 |
|---|---|---|
| 미리보기 `.badge` | `사실` `해석` 이 요약 문장 위로 (26→37px) | `flex-shrink: 0` · `white-space: nowrap` |
| 미리보기 `.summary li > p` | 문단이 배지를 밀어냄 | `flex: 1` · `min-width: 0` |
| 미리보기 `.notice` 글리프 | `ⓘ` 가 4px 로 눌림 (11px 필요) | `> span:first-child { flex-shrink: 0 }` |
| 미리보기 `.star` | 관심목록 `☆` 가 9px 로 눌림 | `flex-shrink: 0` |
| 미리보기 `.pcard-name` | `Nasdaq Composite` 가 카드 밖으로 | 앱의 `truncate` 와 같게 말줄임 |
| 미리보기 `.preview-note code` | 브랜치 이름이 끊길 데가 없어 윗줄과 겹침 | `overflow-wrap: anywhere` |
| 앱 `Notice` | `ⓘ` 가 눌림 | 글리프에 `shrink-0`, 내용에 `min-w-0` |
| 앱 `/more` | 줄 끝 `→` 가 15→12px 로 눌림 | `shrink-0` |

앱의 `Badge` 는 처음부터 `shrink-0 whitespace-nowrap` 이라 멀쩡했고, **미리보기 CSS 에만 빠져 있었습니다.**
같은 화면을 두 벌로 기르는 대가입니다.

찾는 방법은 기계적입니다 — 글자를 담은 잎 요소마다 `scrollWidth > clientWidth` 인지 보고, 인라인 요소와
말줄임(`text-overflow: ellipsis`)과 접힌 `<details>` 안쪽은 뺍니다. 앱 12화면 × 3폭, 미리보기 6보기 × 4폭을
훑어 남는 것이 없는지 확인했습니다. 브라우저 없이는 볼 수 없는 문제라, 되돌아가지 않도록 위 규칙들이
원본에 남아 있는지를 검증에서 확인합니다.

### 같은 말을 두 번 하지 않기

한 화면에서 같은 문장이 두 번 나오면, 읽는 사람은 어느 쪽이 맞는지부터 확인하게 됩니다. 특히 두 벌이 조금씩
어긋나 있으면 서로 다른 주장처럼 읽힙니다. 전 화면의 글자를 훑어 되풀이되는 문장을 찾아 걷어냈습니다.

| 자리 | 무엇이 겹쳤나 | 어떻게 했나 |
|---|---|---|
| 오늘의 시장 요약 | `해석` 배지가 붙은 줄이 문장 끝에서 "이는 …한 해석입니다" 라고 또 말함 | 문장에서 뺌 — 배지가 이미 말하고, 근거는 문장 안에 있음 |
| 오늘의 시장 요약 | "…충분하지 않습니다. 변화 원인을 판단할 데이터가 부족합니다." (같은 말 두 번 + `근거 부족` 배지) | 왜 부족한지 한 문장만 |
| 오늘의 시장 요약 | `자체 산출` 이 머리 · 요약 줄 · 하단 고지에 5회 | 요약 줄은 "심리 점수:" 로 |
| 홈 심리 카드 | 카드 셋이 각각 "○○ 투자심리 / 자체 산출 지수 · v2.1.0" | 셋이 같은 값이라 머리에 한 번만 (`standalone` 이 false 일 때) |
| 심리 상세 · 기간별 위치 | "N일 중 현재 점수보다 낮았던 날의 비율입니다" 를 단기·중기·장기 3회 | 목록 위에 한 번 설명, 각 줄은 숫자만 (읽어주기용 설명은 유지) |
| 심리 상세 | "앞으로를 예측하거나 매매를 권하지 않습니다" 가 위기 표식·구간 통계에 2회 | 각자 제 이야기로 — "기록일 뿐입니다" / "다음에도 같으리라는 보장은 없습니다" |
| 위험 신호등 | 지표 이름이 요약 문장 · 신호등 집계 · 단계별 분포에 3회 | 문장은 개수만(`withNames=false`), 분포는 단계의 뜻을 적음 |
| 장단기 금리차 | "과거 경기침체에 앞서 나타난" 이 `무슨 지표인가` 와 `값이 내리면` 에 2회 | 침체 신호 이야기는 `값이 내리면` 이 담당 |
| 캘린더 | "날짜를 누르면 그날 일정만" 이 머리글과 범례에 2회 | 범례에만 |
| 경제·위험 지표 | 고르지 않은 보기를 `hidden` 으로 감춰만 둬서 같은 해설이 문서에 두 벌 | 아예 그리지 않음 (홈 탭 · 지수 탭과 같은 규칙) |

**가장 깊은 것은 해설이 두 벌이었던 일입니다.** `src/server/risk.ts` 와 `src/lib/indicatorGuide.ts` 가 같은 일곱
지표의 "오르면 / 내리면" 을 각자 들고 있었고, 이미 문구가 갈라져 있었습니다 — VIX 하나만 봐도 `거라고 보는`
과 `거라 보는`. 해설은 **`indicatorGuide.ts` 한 곳에서만** 기르고, 신호등은 거기서 읽어 씁니다
(`us_spread_10_2 → us_spread` 는 별칭으로 잇습니다). 신호등에만 있던 `ust10` · `funding` 해설도 그리로 옮겼습니다.
`risk.ts` 는 이제 눈금 · 구간 · 구간별 문구처럼 신호등에만 있는 것만 듭니다.

되돌아가지 않도록 검증에 못 박았습니다 — 해석 줄이 스스로 "해석" 이라 말하거나, `risk.ts` 가 해설을 다시 들거나,
`무슨 지표인가` 와 `오르면·내리면` 이 14자 넘는 같은 문장을 나눠 가지면 실패합니다.

> **걷어내지 않은 반복도 있습니다.** 차트마다 붙는 `표로 보기` 표는 같은 값을 글로 한 번 더 적지만, 차트를 못
> 보는 사람을 위한 대안이라 그대로 둡니다. 홈 심리 카드가 모바일용 가로 스크롤과 데스크톱용 3열로 두 벌
> 그려지는 것도 그대로입니다 — `.snap-row` 의 `display:flex` 가 `lg:hidden` 을 이기는 문제를 피하려고 일부러
> 그렇게 둔 것이고, `display:none` 쪽은 스크린리더에도 잡히지 않습니다.

### 시장 색

미국·한국·크립토를 눈으로 훑을 때 쓰는 표식입니다 (`--mk-us` / `--mk-kr` / `--mk-crypto` / `--mk-global`,
`marketColor()`).

- **신호등(빨·주·노·연두·초)과 겹치지 않는 색만** 골랐습니다. 겹치면 "위험한 시장"으로 읽힙니다.
  미국 파랑 · 한국 보라 · 크립토 청록 · 글로벌 회색.
- 색은 훑기를 돕는 표식일 뿐이고, **어느 시장인지는 항상 옆의 글자가 말합니다.** 색만으로 시장을 구분하게
  두지 않습니다. 캘린더 각 칸의 스크린리더 라벨에도 "일정 2건, 중요 1건, 크립토 미국"처럼 시장 이름을 적습니다.
- 캘린더 달력에서는 **점의 색이 시장, 점의 크기가 중요도**입니다. 서로 다른 뜻을 서로 다른 채널에 실어
  두 가지를 한 번에 읽게 합니다.

### 캘린더에만 '전체'가 있는 이유

지표·심리 화면에서는 시장을 섞지 않습니다 — 미국 CPI 와 BTC 도미넌스를 한 줄에 세면 "빨간불 1개"가 무슨
뜻인지 알 수 없기 때문입니다. 하지만 **캘린더는 값을 세는 곳이 아니라 시간을 늘어놓는 곳**입니다.
"이번 주에 뭐가 몰려 있나"는 세 시장을 한 번에 봐야 답이 나옵니다. 대신 어느 시장 일정인지는 시장 색과
배지로 늘 보이게 했습니다.

## 10. 데이터 갱신 정책

섹션마다 갱신 주기가 다릅니다 (`src/server/config.ts`).

| 섹션 | TTL | 오래됨 판정 |
| --- | --- | --- |
| 세션 | 10초 | 1분 |
| 시세 | 30초 | 5분 |
| 수급 | 2분 | 15분 |
| 시장 위험 신호등 | 2분 | 15분 |
| 심리 점수 | 5분 | 3시간 |
| 뉴스 / 요약 | 5분 | 3시간 |
| 캘린더 | 15분 | 6시간 |
| 거시 지표 | 6시간 | 48시간 |

- 클라이언트는 30초마다 스냅샷을 확인하고, 서버는 섹션별 TTL 로 실제 갱신 주기를 나눕니다.
- 갱신 실패 시 **마지막 정상 데이터**를 계속 보여주고 "갱신 실패" 배지를 띄웁니다.
- "오래된 데이터" 판정은 제공사 계약상 지연 시간을 뺀 뒤 계산합니다. 15분 지연 시세는 정상이지 오래된 데이터가 아닙니다.
- 서비스 워커는 **`/api/*` 를 캐시하지 않습니다.** 오프라인에서 오래된 시세를 최신인 척 보여주지 않기 위해서입니다.

## 11. 기술 스택

- **Next.js 15** (App Router) · **React 19** · **TypeScript** (strict)
- **Tailwind CSS 4** (CSS 변수 기반 토큰, 다크/라이트)
- 차트: **의존성 없는 자체 SVG 차트** (게이지·스파크라인·듀얼 축 라인·기여도 막대)
  — 툴팁·키보드 탐색·표 대안을 직접 제어하기 위해 라이브러리 대신 직접 구현했습니다.
- PWA: 직접 작성한 `manifest.webmanifest` + `sw.js` (빌드 의존성 없음), 아이콘은 `scripts/generate-icons.mjs` 가 PNG 로 생성
