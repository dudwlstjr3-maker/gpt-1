# 변경 기록

새 항목을 위에 쌓는다. 날짜는 KST.

## 2026-10-29 — 규칙 파일의 틀린 내용을 고친다

검토에서 반려된 것을 고쳤다. 규칙 파일이 엉뚱한 파일을 가리키면
없는 것보다 나쁘다 — 그대로 믿고 그 파일을 고치면 화면은 그대로이기 때문이다.

- **하단 고지의 자리를 바로잡았다.** `src/app/layout.tsx` 라고 적었는데 틀렸다.
  실제 문구는 `src/components/market/constants.ts:11`(`DISCLAIMER_TEXT`) 에 있고,
  `src/components/ui/Disclaimer.tsx:20` 에서 그려지고,
  `tools/preview/template.html:920` 에 사본이 있다 — 세 곳 규칙이 걸리는 자리다.
  `layout.tsx:10` 의 것은 검색엔진용 `metadata.description` 이고 화면에 나오지 않는다.
  AGENTS.md 에 그 구분을 적어 뒀다.
- **"새로 만든 규칙은 없다" 는 말을 거뒀다.** 1~5절은 이미 있던 약속을 모은 것이지만,
  6절(main 직접 푸시 금지 · 브랜치 → PR → 승인 후 병합 · 강제 푸시 금지)은
  `origin/main` 어디에도 글로 없었다. 새로 적는 규칙이라고 그 절에 밝혔다.
  어제 커밋 메시지와 이 파일에도 같은 말이 들어가 있었다.
- **검사 건수를 세어서 맞췄다.** 1,227 이라는 숫자는 직접 센 것이 아니었고,
  README 는 729건·단위 62건이라고 적고 있어 저장소가 서로 다른 말을 했다.
  개발 서버를 띄우고 실제로 돌려 센 값으로 통일했다 — 검증기 **1,204건**, 단위 **137건**
  (2026-10-29, DEMO 모드). `README.md:917-918` 도 그 값으로 고쳤다.
- **`src/server/` 를 구조 설명에 넣었다.** 키를 읽는 `config.ts` 와 LIVE 어댑터가 있는
  곳인데 빠져 있었다. 2절의 키 규칙이 실제로 걸리는 자리다.
- **`npm test` 와 검증기 `[0]` 단계가 같은 검사임을 적었다.** `verify.mjs:55-69` 가
  `scripts/*.test.mjs` 를 찾아 `node --test` 로 태운다. 서로 다른 검사 두 벌이 아니라,
  `npm test` 는 그 단계를 서버 없이 떼어 돌리는 입구다.
- **`.gitignore` 설명을 사실대로 고쳤다.** 이 파일에 `.env*` 가 다 걸러진다고 적었는데
  아니다. `.gitignore:9-11` 에는 `.env`, `.env.local`, `.env*.local` 만 있어
  **`.env.production` 은 걸러지지 않는다.** 파일은 그대로 두고 설명을 고쳤고,
  그런 이름을 쓰지 말라고 AGENTS.md 2절에 적었다.
- CLAUDE.md 의 파일 크기를 실제 바이트로 바꾸고, 빠져 있던 `tools/preview/template.html`
  (339,299B — verify.mjs 보다 크다) 을 넣었다.

앱 동작은 바뀐 것이 없다.

## 2026-10-28 — 개발 환경을 정리한다

사람마다, 에이전트마다 검사 돌리는 방법이 달라서 생기는 낭비를 없앴다.

- **`npm test` 를 만들었다.** `node --test scripts/*.test.mjs` (137건).
  그동안 명령이 없어서 매번 손으로 적어야 했다.
  `npm run verify` 와는 별개로 둔다 — `verify` 는 `:3000` 에 뜬 서버가 필요하고
  `npm test` 는 서버 없이 어디서나 돌아야 하기 때문이다.
- **CI 를 붙였다.** `.github/workflows/ci.yml` — PR 과 main 푸시에서
  `npm ci` → `typecheck` → `test` → `build` 를 Node 22 로 돌린다.
  `verify` 는 서버가 필요해서 CI 에서 빼고, 각자 기계에서 돌린다 (이유는 워크플로 주석에).
- **`AGENTS.md` 를 만들었다.** 코드와 README 에 흩어져 있던 약속을 한곳에 모았다 —
  투자 추천 금지, 하단 고지, 키는 서버 환경변수로만, LIVE/DEMO 분리, 결측 0 보정 금지와
  70% 문턱, 외부 지수 복제 금지, 색만으로 뜻 전하지 않기, 세 곳 규칙, 검증 순서, 브랜치 규칙.
- **`CLAUDE.md` 를 만들었다.** 규칙은 `AGENTS.md` 를 가리키게만 하고,
  Claude Code 에서만 걸리는 것들(verify 전에 개발 서버를 다른 프로세스로 띄우기 등)만 적었다.

앱 동작은 바뀐 것이 없다.
