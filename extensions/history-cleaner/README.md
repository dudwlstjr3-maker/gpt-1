# 기록 지우개 — Chrome 확장 프로그램

인터넷 사용 기록(방문 기록)을 정해 둔 때에 자동으로 지웁니다.
Chrome · Edge · Whale 등 Chromium 계열 브라우저에서 동작합니다 (Manifest V3).

## 설치

1. 이 폴더(`extensions/history-cleaner`)를 컴퓨터에 내려받습니다.
2. 주소창에 `chrome://extensions` 를 엽니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더를 고릅니다.

설치하면 설정 화면이 한 번 열립니다. 이후에는 툴바의 퍼즐 아이콘에서 '기록 지우개'를 고정해 두고 누르면 됩니다.
폴더를 옮기거나 지우면 확장도 사라지니 고정된 곳에 두세요.

## 기능

| 설정 | 기본값 | 하는 일 |
| --- | --- | --- |
| 자동 삭제 (오른쪽 위 스위치) | 켬 | 아래 자동 동작 전체를 켜고 끕니다. 꺼도 '지금 지우기'는 됩니다. |
| 주기 | 1시간마다 | 15분 ~ 하루마다 지웁니다. |
| 브라우저를 닫으면 지우기 | 켬 | 창을 모두 닫을 때 지우고, 다음에 켤 때 한 번 더 지웁니다. |
| 방문 기록 | 전부 지우기 | '최근 1시간/1일/7일/30일은 남기기'를 고르면 그보다 오래된 것만 지웁니다. |
| 함께 지울 것 | 모두 끔 | 다운로드 목록 · 캐시 · 쿠키 · 양식 자동완성. 기간과 상관없이 전부 지웁니다. |
| 바로 지울 사이트 | 없음 | 적어 둔 사이트(하위 주소 포함)는 방문하는 즉시 기록에서 지웁니다. 저장하면 이미 남은 기록도 지웁니다. |
| 지금 지우기 | — | 위 설정대로 바로 지웁니다. 실수 방지로 두 번 눌러야 합니다. |

## 알아 둘 것

- **지운 기록은 되살릴 수 없습니다.** 처음 설치하면 1시간 뒤, 또는 브라우저를 닫을 때 첫 삭제가 일어납니다.
- Google 계정 **동기화가 켜져 있으면 같은 계정의 다른 기기 기록도 함께 지워질 수 있습니다.**
- **쿠키**를 고르면 사이트 로그인이 풀립니다.
- 창을 닫자마자 브라우저가 꺼지면 그때는 다 못 지울 수 있습니다. 그래서 다음에 켤 때 한 번 더 지웁니다.
- 시크릿 창은 원래 방문 기록이 남지 않으므로 따로 할 일이 없습니다.
- 이 확장은 기록을 읽어 밖으로 보내지 않습니다. 네트워크 요청이 없고, 설정은 이 브라우저 안(`chrome.storage.local`)에만 저장합니다.

## 권한

| 권한 | 쓰는 곳 |
| --- | --- |
| `history` | 방문 기록 삭제, '바로 지울 사이트' 감지 |
| `browsingData` | 다운로드 목록 · 캐시 · 쿠키 · 자동완성 삭제 |
| `alarms` | 주기 삭제 |
| `storage` | 설정과 마지막 삭제 시각 저장 |

## 개발

- 아이콘 다시 그리기: `node tools/history-cleaner/icons.mjs`
- 실제 Chromium 에 올려 전체 기능 확인 (빈 프로필을 새로 만들어 쓰므로 평소 기록은 건드리지 않음):

  ```bash
  npm i --no-save playwright && npx playwright install chromium
  node tools/history-cleaner/e2e.mjs [스크린숏 저장 폴더]
  ```
