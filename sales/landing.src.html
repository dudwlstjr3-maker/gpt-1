01 — 자체 산출

Fear & Greed 를 가져오지 않고 직접 계산합니다

외부 지수를 긁어오는 게 아니라 공개 데이터로 산출합니다. 구성요소·가중치·정규화 방식이 전부 코드와 문서에 공개되어 있고, 점수 옆에 무엇이 몇 점 기여했는지가 그대로 표시됩니다.

가중치를 바꾸려면 파일 하나만 고치면 됩니다 — src/server/fng/definitions.ts

02 — 키 없이 실행

지금 받아서 지금 띄울 수 있습니다

API 키가 하나도 없어도 DEMO 모드로 전체 화면이 뜹니다. 고정 샘플 데이터라 스크린샷, 클라이언트 시연, 퍼블리싱 검수에 바로 씁니다.

DEMO 와 실데이터는 같은 응답 안에서 절대 섞이지 않습니다. 모드는 스냅샷 단위로 하나이고, DEMO 일 때는 상태바와 모든 카드에 배지가 붙습니다.

03 — 무료 제공사

유료 데이터 구독 없이 돌아갑니다

무료 키 하나(FRED)만 발급받으면 됩니다. 나머지 일곱 곳은 키가 아예 필요 없습니다.

04 — 거절하는 설계

못 하는 것을 화면이 직접 말합니다

값을 못 받으면 빈칸이나 0 대신 왜 못 받는지를 그 자리에 씁니다. 한국 투자자 수급, 52주 신고가, FOMC 일정은 무료 소스가 없어서 못 붙였고, 그 사실이 코드 주석이 아니라 화면과 문서에 적혀 있습니다.

구간 기준도 "이 앱이 정한 값이며 공식 기준이 아니다"라고 화면에 그대로 씁니다. 금융 앱에서 제일 손이 많이 가는 부분이고, 이미 되어 있습니다.

05 — 인수인계 문서

1,039줄짜리 README 가 "왜"까지 적혀 있습니다

산출식, 구간 기준, 데이터 갱신 정책, 화면 설계 근거, 한국을 시장에서 뺀 이유, 캘린더를 FRED 로 한 이유까지. 결정의 이유가 남아 있어 인수인계 문서를 따로 쓸 필요가 없습니다.
