쫄탐일보 — 내 컴퓨터에서 켜기
==============================

1) Node.js 설치 (처음 한 번)
   - https://nodejs.org/ 에서 왼쪽 'LTS' 버튼으로 받아 설치합니다. 설정은 그대로 두고 '다음'만 누르면 됩니다.
   - 설치가 끝나면 열려 있던 창을 모두 닫습니다.

2) 실행
   - 쫄탐일보 폴더 맨 위의 start.bat 을 더블클릭합니다.
   - 처음 한 번은 부품 설치와 앱 만들기에 몇 분 걸립니다. 다음부터는 바로 켜집니다.
   - 준비되면 브라우저가 http://localhost:3000 으로 저절로 열립니다.
   - 끌 때는 검은 창을 닫거나 Ctrl+C 를 누릅니다.

3) 실제 시세(LIVE)로 보기 — 선택
   - 키가 없으면 DEMO(샘플 데이터)로 켜집니다. 화면 위의 DEMO 배지로 알 수 있습니다.
   - .env.example 을 복사해 이름을 .env.local 로 바꾸고, MACRO_API_KEY 에 FRED 무료 키를 넣습니다.
     https://fred.stlouisfed.org/docs/api/api_key.html
   - 저장한 뒤 start.bat 을 다시 실행하면 LIVE 로 켜집니다. 검은 창에 '지금 모드'가 나옵니다.
   - .env.local 은 내 컴퓨터에만 둡니다. 누구에게도 보내거나 올리지 마세요.

4) 잘 안 될 때
   - "3000 번 문을 다른 프로그램이 쓰고 있습니다" → 다른 쫄탐일보 창을 닫거나 컴퓨터를 다시 켭니다.
   - 화면이 예전 그대로이면 → start.bat --rebuild (명령 창에서) 로 다시 만듭니다.

본 서비스는 정보 제공 목적이며 투자 조언이 아닙니다.
